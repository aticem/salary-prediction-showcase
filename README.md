# Software Engineer Salary Prediction

> 🔒 **Showcase** — the source code is private. Walkthrough available on request via [LinkedIn](https://www.linkedin.com/in/acsamiloglu/).

End-to-end ML project predicting software-engineer salaries by country, from the Stack Overflow developer survey, served as an interactive web app.

## Features
- Data cleaning and exploratory analysis
- scikit-learn model tuned with cross-validation and grid search
- Streamlit app with a prediction page and an explore page

## Tech stack
Python · pandas · NumPy · scikit-learn · Streamlit
